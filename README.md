
Esse site é feito com o [Zola](https://www.getzola.org).

## Alterações Locais

Para modificar e visualizar o site localmente deve-se clonar o repositório com o
site e instalar o Zola:

MacOS:

    brew install zola

Linux:
	 sudo apt install zola
	 pacman -S zola

Windows:
	winget install getzola.zola


Rode `zola serve` para iniciar o servidor local.
